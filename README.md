# 🏦 Python Bank Management System

A simple Bank Management System built using Python.  
The project allows users to create accounts, manage their balance, transfer money, and update their personal information.

This project was developed as part of my learning journey in Python.

---

## ✨ Features

- User Registration
- User Login
- Deposit Money
- Withdraw Money
- Transfer Money Between Accounts
- View Personal Profile
- Edit Personal Information
- Delete Account
- Multi-Currency Deposit Support
- JSON Database Storage

---

## 🛠 Technologies Used

- Python 3
- JSON
- File Handling
- Functions
- Dictionaries
- Loops
- Conditional Statements

| Currency | Rate |
|----------|------|
| EGP | 1 |
| USD | 50 |
| SAR | 14 |
| SDG | 2 |

The deposited amount is automatically converted into Egyptian Pounds (EGP).

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Python-Bank-Management-System.git
```

2. Navigate to the project folder

```bash
cd Python-Bank-Management-System
```

3. Run the program

```bash
python bank.py
```
